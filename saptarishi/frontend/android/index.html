1. Product structure

Keep current website features visible, add space for future growth

The app should not hide existing tools behind desktop-style tables. It should give one-tap access to current tools and reserve menu positions for upcoming modules without forcing another navigation redesign later.

01

Bottom navigation

Home, Kundali, Remedy, Calendar, and Menu remain reachable from every main screen.

02

Home as dashboard

Show free query usage, premium status, continue cards, and primary astrology actions.

03

Menu as all-options hub

Current pages, account, support, privacy, and future features live in a grouped menu.

04

Results become cards

Large website tables are converted into tabs, cards, sticky summary, and detail sheets.

2. App information architecture

Where each feature will live

Home

  • Option menu, Saptarishi brand, wallet, profile
  • Large Kundali, Remedy, Auspicious, Matching, Compare
  • Second footer: Call and Ask
  • Bottom: Home, Dasha, Horoscope, Do's & Don't

Kundali

  • Person name for the chart
  • Birth place, date, and time
  • Open Kundali primary action
  • Symbol strip and feature previews
  • Kundali compare and result tabs

Remedy

  • 12 house tiles (same as menu)
  • Personality through Expenses
  • House-linked planet remedies
  • Expandable detail cards

Calendar

  • Auspicious muhurat tiles: birth, marriage, home, vehicle, travel
  • From date and to date
  • Top slots and lord comparison
  • Future muhurat calendar

Menu

  • Profile: edit details, wallet, buy premium, login/logout
  • Support: WhatsApp, phone, email
  • Privacy
  • Reports, Panchang, Horoscope, Kundali Matching, Marriage, Career, Child, Past Life, Pooja
